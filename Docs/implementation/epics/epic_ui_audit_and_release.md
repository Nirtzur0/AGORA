# Epic: UI Audit and Release Discipline

## Goal

Improve confidence in user-facing audit workflows while hardening release documentation and CI mapping.

## User Stories

- As a reviewer, I need stable UI flows for project/workspace audit tasks.
- As a maintainer, I need a repeatable release-readiness path tied to canonical commands.

## Tasks

- Expand/maintain E2E checks for key UI pages.
- Align CI jobs with runbook command IDs.
- Create and enforce release-readiness checklist artifacts.
