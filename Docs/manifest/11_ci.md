# CI

CI is implemented with GitHub Actions in `.github/workflows/ci.yml`.

## Current Jobs

- `docs-guardrail`
  - Enforces docs updates when tests/CI/runtime files change.
  - Requires:
    - `Docs/implementation/00_status.md`
    - `Docs/implementation/03_worklog.md`
    - at least one file under `Docs/implementation/checklists/`
  - Additional alignment freshness enforcement:
    - when `Docs/implementation/checklists/07_alignment_review.md` changes, it must include `Triggering delta:` and `Recommended next non-redundant packet:`
    - status/worklog must include triggering-delta context for the same change set
- `cmd-11-fast-checks`
  - Enforces runbook `CMD-11` equivalent (`make test`: stubs + unit).
- `cmd-12-integration`
  - Enforces guarded runbook `CMD-25` (`make test-all-guarded`: stubs + unit + integration with Temporal preflight and one retry on transient startup failures) with infra boot.
- `paper-verification-gate`
  - Enforces runbook `CMD-33` (paper invariant harness + paper/code map contract checks).
  - Enforces runbook `CMD-34` (deterministic paper verification snapshot generation).
  - Publishes `paper/artifacts/verification_snapshot.json` as `paper-verification-report`.
- `observability-gate`
  - Enforces runbook `CMD-26` (`make check-observability-slos`) for artifact provenance/freshness SLO thresholds.
- `architecture-coherence`
  - Enforces runbook `CMD-28` (`make check-architecture-coherence`) for architecture-doc and CI/runbook wiring coherence.
- `objective-metrics-gate`
  - Enforces runbook `CMD-29` (`make check-objective-metrics`) for objective-metric regression automation (citation integrity + authority boundary).
  - Also enforces runbook `CMD-32` (`make check-observability-snapshot`) for consolidated observability signal synthesis.
  - Publishes durable CI artifacts:
    - objective metrics bundle (`objective_metrics_latest.json`, `objective_metrics_dashboard.md`, `objective_metrics_history.jsonl`, `objective_metrics_timeline.md`) as `objective-metrics-report`
    - observability snapshot bundle (`observability_snapshot_latest.json`, `observability_snapshot_dashboard.md`) as `observability-snapshot-report`
  - Writes objective + observability dashboard content to job summary output.
- `cmd-13-e2e-critical-flow`
  - Enforces runbook `CMD-27` (`make test-e2e-critical`) for one deterministic critical workflow outside release-only runs.
  - Applies warning-budget enforcement (`E2E_CRITICAL_WARNING_BUDGET=40`) so warning regressions fail the gate.
- `cmd-13-nightly-full-suite`
  - Enforces runbook `CMD-13` (`make test-e2e`) on nightly schedule.
  - Applies warning-budget enforcement (`E2E_FULL_WARNING_BUDGET=200`) for full e2e signal quality.
  - Can also be triggered manually via `workflow_dispatch` input `run_full_e2e=true`.
- `cmd-37-38-dash-data-quality`
  - Enforces runbook `CMD-37` and `CMD-38` for Dash data-quality validation + regression tests.
  - Publishes `/tmp/agora-dash-validation.json` as `dash-data-quality-report`.
- `release-tag-gate`
  - Enforces fail-closed release validation for `v*` tags.
  - Runs runbook `CMD-11`, `CMD-25`, `CMD-27`, `CMD-13`, `CMD-37`, `CMD-38` plus release-readiness evidence checks.
  - Applies full e2e warning-budget enforcement (`E2E_FULL_WARNING_BUDGET=200`) inside the release command sequence.
  - Can also be triggered manually via `workflow_dispatch` input `run_release_gate=true`.
- `cmd-30-ui-smoke-cross-browser`
  - Enforces runbook `CMD-30` by running UI smoke in a browser matrix (`chromium`, `firefox`, `webkit`) with deterministic fixture setup and provenance drill-down assertions.
  - Publishes per-browser smoke screenshots as CI artifacts (`ui-smoke-<browser>`).
- `cmd-31-ui-smoke-mobile`
  - Enforces runbook `CMD-31` by running UI smoke at mobile viewport width and asserting all workspace tabs remain reachable.
  - Publishes mobile smoke screenshot artifact (`ui-smoke-mobile`).
- `smoke-test`
  - Boots compose infra, starts Core API, checks `/health`.

## Release/Promotion Trigger Paths

`AR-C04` + `AR-C05` are implemented in `.github/workflows/ci.yml`:

- `cmd-13-nightly-full-suite`:
  - trigger: nightly schedule (`0 7 * * *`) + `workflow_dispatch` (`run_full_e2e=true`)
  - runbook mapping: `CMD-13`
  - purpose: maintain fresh full-e2e confidence for release promotion with warning-noise guardrails.
- `release-tag-gate`:
  - trigger: `push` on `v*` tags + `workflow_dispatch` (`run_release_gate=true`)
  - runbook mapping: `CMD-11`, `CMD-25`, `CMD-27`, `CMD-13`, `CMD-37`, `CMD-38`
  - purpose: fail-closed release validation before release publication, including full-e2e warning-budget enforcement.
